- [x] **1. Build atomic-write/append Node scripts**
  Spec ref: `spec.md > Component: Foundation > scripts/atomic-write-json.js + atomic-append-jsonl.js`
  What to build: Two Node single-file scripts at `scripts/atomic-write-json.js` and `scripts/atomic-append-jsonl.js`. Both zero-dependency. `atomic-write-json.js` reads JSON from stdin, ensures parent directory exists, writes to `<target>.tmp`, fsyncs, atomic-renames to `<target>`. `atomic-append-jsonl.js` reads one JSON object from stdin, ensures directory exists, opens file with `O_APPEND | O_WRONLY | O_CREAT`, writes serialized line + `\n`. Both exit 0 on success, exit 1 with stderr message on failure.
  Acceptance: Both scripts exist and are executable. Running `echo '{"foo":"bar"}' | node scripts/atomic-write-json.js /tmp/test.json` produces a valid JSON file. Running `echo '{"event":"test"}' | node scripts/atomic-append-jsonl.js /tmp/test.jsonl` appends a single line ending in `\n`. Invalid JSON in stdin causes exit 1 with `"invalid JSON: ..."` to stderr. Parent directory creation works for paths that don't yet exist.
  Verify: Run both scripts against `/tmp/` test paths with valid JSON, confirm files contain expected content. Run with malformed JSON, confirm exit 1 + clean stderr message. Run write-script targeting a path with non-existent parent dir, confirm dir is created.
